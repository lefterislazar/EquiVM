`NestedCaller.nestedCallerCorrect` proves full `runtimeEquivalence` between the
compiled runtime of `NestedCaller.sol` and `nestedCallerContract` under
`nestedCallerConfig`. It covers dispatch, ABI decoding, the function body, and
return encoding. Constructor equivalence is outside this example.

The contract loops over `sample(target, i)`, an internal helper that reads
`gasleft()` and either returns zero or calls `target.probe(i)`. A result of zero
continues; one breaks; any other result becomes `last`. The contract returns
`last`. Both representations enforce `count <= 16`, keeping cumulative memory
growth bounded without adding a premise to the runtime theorem. There is no
storage or arithmetic beyond comparisons and the loop increment.

The proof permits arbitrary target code, external call outcomes, return data,
and related initial account maps. It preserves the account relation across
calls, including account changes caused by reentrancy. Failed calls and short
return data lead to matching reverts. Out-of-gas behavior is handled by the
existing RD/refinement judgments; the example does not split on it or on call
depth and balance checks.

| File | Role |
| --- | --- |
| `Spec.lean` | Solm contract and external ABI |
| `Bytecode.lean`, `Blocks.lean` | Generated bytecode, jump destinations, 78 RD summaries |
| `ControlFlow.lean` | Loop invariant, post, break/continue, internal-call composition |
| `Sample.lean` | Explicit `gasleft()` and the helper's two paths |
| `CallMemory.lean` | Free-pointer, memory and ABI facts across repeated calls |
| `CallTraces.lean` | Generated-summary composition around CALL and its decoder |
| `External.lean` | Paired external-call refinement |
| `Body.lean` | Count guard, loop initialization, loop and return tail |
| `Dispatch.lean`, `Correct.lean` | ABI/dispatcher paths and complete runtime theorem |
| `Audit.lean` | Check of the final theorem's axiom dependencies |

The loop uses `StmtsRefine` with an invariant relating stack words, source locals,
memory, and the current account maps. Its decreasing variant is `count - i`.
The internal helper is proved independently and supplied to the loop body;
the final theorem discharges that obligation. `BlockRefinesFrom.letGas` handles
the source gas read, `BlockRefinesFrom.gas` handles the compiler's forwarding-gas
read, and `BlockRefinesFrom.externalCall` handles CALL and its continuation.
`BlockRefinesFrom.toRuntimeEquivalenceFor` connects the body to runtime execution.

The compiler preserves the helper as an actual internal jump/return:

| Boundary | PC |
| --- | --- |
| Decoded body / count guard | 93 |
| Loop header / body / post / exit | 116 / 125 / 169 / 180 |
| Internal helper entry / caller continuation | 191 / 135 |
| Explicit GAS / low-gas return / external-call prefix | 194 / 207 / 215 |
| Forwarding GAS / CALL / call-result continuation | 284 / 285 / 286 |
| Call-failure revert / successful-call decoder entry | 293 / 613 |
| Helper's dynamic return | 340 |

Summaries stop at both GAS instructions and at CALL. The generation check also
verifies these positions, the retained internal jump/return, and the absence of
storage and creation opcodes.

Reproduce and check from the repository root with `solc` on PATH:

```sh
python3 Examples/NestedCaller/generate.py --check
lake build Examples.NestedCaller.Audit
python3 scripts/test_generate_rd_blocks.py
```

Omit `--check` to regenerate the two generated Lean files. The script requires
solc **0.8.34+commit.80d5c536**, using the legacy pipeline, optimizer disabled,
Shanghai EVM, and no appended CBOR metadata. The resulting runtime is 656 bytes
with 50 jump destinations. It checks both function selectors against solc's
method identifiers.

This example required two generic additions: typed/raw call bridges for the
existing gas-derived return-data length bound, and word-write memory lemmas
without the old, unused host-size restriction on the zero gap. The original
memory lemma interfaces remain available. The allocation invariant uses the
derived `returnData.size < 2^138` bound, allowing arbitrary return sizes within
the EVM model rather than assuming a one-word response.

The explicit new axiom is the concrete Keccak selector fact `runSelectorBytes`,
following the existing examples. `Audit.lean` also permits Lean's standard
logical axioms, generated `native_decide` certificates, and seven existing EVM
precompile output-size assumptions used by the return-data bound. It rejects
other axiom dependencies, including `sorryAx`.
